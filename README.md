## 📖 Тема проекта :
    Библиотека обработки изображений на С с базовыми алгоритмами компьютерного зрения
## 🚀 Инструкция запуска :
    Для тестирования следует использовать скрипты из папки scripts (запускаем lib.bat -> запускаем test.bat)
## 📁 Содержание :
```
    ├── 📂 functions - хранит фильтры, вспомогательные функции, хедер
    │   ├── Edges_detect.c   - Детектор границ
    │   ├── Gauss_filter.c   - Гауссово размытие
    │   ├── Gradation_grey.c - Градации серого
    │   ├── header.h         - Главный заголовочный файл
    │   ├── Inversion.c      - Инверсия цветов
    │   ├── Median_filter.c  - Медианный фильтр
    │   ├── ReSize.c         - Масштабирование
    │   ├── Turner_alpha.c   - Поворот на произвольный угол
    │   ├── Turner_left.c    - Поворот влево
    │   ├── Turner_up.c      - Поворот вверх
    │   └── helper_func.c    - Вспомогательные функции
    │       ├── reflect         - Отражение пикселей
    │       ├── compare         - Сравнение
    │       ├── g/gx/gy         - Функции свертки
    │       ├── newCoorX/Y      - Расчет координат
    │       ├── BilinalInterpol - Билинейная интерполяция
    │       └── GetNewCoor      - Координаты при масштабировании
    ├── 📂 images  - тестовые изображения
    ├── 📂 libs    - сторонние библиотеки
    ├── 📂 scripts - скрипты управления
    │   ├── delete.bat - сброс проекта
    │   ├── lib.bat    - сборка библиотеки
    │   └── test.bat   - запуск тестов
    ├── 📂 tests - результаты обработки
    ├── 🗑️ trash - временные файлы
    ├── main.c - интерфейс библиотеки
    └── 📝 README.txt - документация
```
